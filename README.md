# It's Me Link

인스타그램 프로필에 사용할 수 있는 반응형 링크 페이지입니다. 별도 빌드 과정 없이 GitHub Pages에서 바로 동작합니다.

## 내용 바꾸기

- `index.html`에서 이름, 소개, 링크, 이메일을 수정하세요.
- `styles.css`의 `--accent` 값을 바꾸면 포인트 색상을 변경할 수 있습니다.
- 프로필 사진을 사용하려면 이미지를 프로젝트에 추가하고 `.avatar` 영역을 이미지 태그로 교체하세요.

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더를 푸시합니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택합니다.
3. `main` 브랜치에 푸시할 때마다 자동으로 배포됩니다.
